# 🎵 Moodify

Moodify is an AI-powered music recommendation web application that detects a user's facial emotion and recommends music based on their current mood.

## ✨ Features

- 🎭 Facial emotion detection
- 🎵 Mood-based music recommendations
- 🔐 User authentication
- 👤 User registration and login
- 📱 Responsive React frontend
- ⚡ Node.js + Express backend
- 🗄️ MongoDB database
- 🔄 REST API architecture
- 🖼️ Image/media handling
- 🎧 Personalized music experience

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### AI / Computer Vision
- MediaPipe Face Landmarker
- Facial emotion analysis

### Other Tools
- Git & GitHub
- REST APIs
- ImageKit / Multer
